# Pahal - AI-Powered Emergency Response System

 Saving lives through faster response with real-time AI detection and community reporting.

## Features

-  **AI Detection** - Smart cameras automatically detect accidents
-  **Community Reports** - Quick incident reporting with photos
-  **Hotspot Mapping** - Visualize accident-prone areas
-  **Admin Dashboard** - Real-time command center
-  **Analytics** - Track response metrics and trends

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Radix UI
- React Router
- Lucide Icons
